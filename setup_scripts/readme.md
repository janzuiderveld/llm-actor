Setup scripts for easy installation. Get the files from here or the [Releases](https://github.com/RVirmoors/llm-actor/releases) page.

* Windows: run `setup.bat` and follow on-screen instructions.
* Mac:
  * download `setup_mac.zip` and unzip it
  * open a Terminal and `cd` to your unzipped folder, e.g. `cd Downloads/setup_mac` 
  * `chmod +x setup.command`
  * `chmod +x run.command`
  * `sudo ./setup.command` and follow on-screen instructions.
